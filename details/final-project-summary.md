# Final Project — Urban Scooter (Web & API)

🔗 [View the full project repository](https://github.com/jamileazeredo/qa-final-project-urban-scooter)

This is the capstone project of the TripleTen QA Bootcamp: end-to-end test case
design and execution for the Urban Scooter application, covering both the web
front-end and the backend API. I designed and executed positive and negative
test cases for the customer registration form, applying equivalence partitioning
and boundary value analysis — including internal limits such as 1, 2, 3, 14, 15,
and 16-character name inputs. On the backend side, I validated courier creation
and deletion endpoints against a PostgreSQL database, covering duplicate logins,
numeric characters, and special characters. All bugs found were documented in
Jira with clear reproduction steps.
